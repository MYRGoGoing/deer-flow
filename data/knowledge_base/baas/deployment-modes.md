# BaaS 部署方式

BaaS（Blockchain as a Service）平台为联盟链网络提供一键部署、监控运维、成员管理等全生命周期能力。

## 三种部署形态

| 形态 | 适用场景 | 特点 |
|------|---------|------|
| SaaS 托管 | 快速试用、轻量应用 | 平台方代运维，开通即用 |
| 私有化部署 | 金融、政务等强合规场景 | 全套组件部署在客户机房，数据不出域 |
| 混合云 | 跨机构联盟 | 各机构本地保留核心节点，管控面托管在云端 |

## 私有化部署要求

1. 操作系统：主流 Linux 发行版（CentOS、Ubuntu 等）。
2. 容器环境：基于 Kubernetes 编排，节点以容器方式运行。
3. 硬件基线：共识节点建议 8C16G 起步，SSD 磁盘。
4. 网络：节点间互通所需端口需在防火墙放行。

## 一键部署流程

1. 在 BaaS 控制台创建联盟与成员。
2. 选择部署形态与资源池，填写节点规格。
3. 平台自动拉起区块链节点并完成证书分发。
4. 部署完成后可在控制台查看节点健康度、TPS、区块高度等监控指标。

## 升级与扩容

支持滚动升级底层版本；扩容共识节点时经联盟审批后自动加入共识集合，无需停链。

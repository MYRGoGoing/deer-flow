# 趣链区块链平台概述

Hyperchain 是趣链科技自主研发的企业级联盟区块链底层平台，面向金融、政务、供应链等场景提供分布式账本能力。平台于 2016 年启动研发，核心团队来自浙江大学区块链研究团队。

## 核心特性

- **高性能**：采用优化的拜占庭容错共识算法 RBFT，单链交易吞吐量可达万级 TPS。
- **国密支持**：完整支持国家商用密码算法 SM2、SM3、SM4，同时兼容 ECDSA、SHA-256 等国际算法。
- **双合约引擎**：同时支持自研 Java 合约引擎 HVM 与以太坊 EVM 虚拟机，兼顾主流生态与企业级开发习惯。
- **可插拔架构**：共识模块、密码套件、存储引擎均可按需替换，便于适配不同行业合规要求。
- **多账本隔离**：通过 namespace 命名空间机制实现业务数据隔离，不同业务方可共享底层网络而互不可见。

## 典型应用领域

平台已在以下领域规模化落地：

1. 金融行业：数字票据、供应链金融、跨境支付对账。
2. 政务服务：电子证照存证、司法存证、政务数据共享。
3. 能源与碳交易：绿证溯源、碳排放数据核证。

## 开放联盟链

除私有化部署外，趣链科技还运营开放联盟链品牌"飞洛"（FiLoop），为中小企业提供低门槛的链上服务接入方式。

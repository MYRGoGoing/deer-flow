# BitXHub 跨链平台概述

BitXHub 是趣链科技开源的跨链技术方案，采用中继链架构解决异构链之间的资产互换与合约互操作问题。

## 总体架构

三类角色组成：

1. **应用链**：需要互操作的现有区块链（Hyperchain、Fabric、以太坊等）。
2. **跨链网关 Pier**：部署在应用链侧，负责跨链交易的捕获、协议转换与证明传递。
3. **中继链**：一条独立的区块链，负责应用链注册、跨链交易路由与验证规则管理。

## IBTP 协议

跨链消息统一封装为 IBTP（InterBlockchain Transfer Protocol）结构，包含来源链、目标链、payload 与证明信息。Pier 将各链原生交易转换为 IBTP 报文，中继链按路由规则投递到目标链网关。

## 验证机制

应用链注册时向中继链提交验证人集合与验算规则。中继链上的验证合约依据该规则校验跨链证明的真实性，防止伪造跨链消息。

## 典型场景

- 数字资产在不同联盟链间的兑换与转移。
- 主链存证、侧链业务的多级架构。
- 与 Fabric 业务链互通的数据协同。

开源代码仓库位于 GitHub 的 meshplus/bitxhub 项目，包含中继链、Pier 网关与验证引擎组件。
